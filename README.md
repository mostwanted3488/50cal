# .50 (DOT50)

Plugin d'effets audio BUYORBEALOSER : un stand de tir minimaliste (Desert Eagle, fond gris et grille). 8 cibles = 8 effets
(REVERB, DELAY, CHORUS, DRIVE, CRUSH, FILTER, PHASER, FLANGER) ; on tire sur une cible pour activer ou couper son effet.
Mode TRYHARD (pastille en haut à gauche) : 30 s façon Aimlab, avec précision, kills/s et time-to-kill.

- Formats : VST3 + AU + Standalone (macOS universel, 11+), VST3 + Standalone (Windows x64)
- Le fichier s'appelle `DOT50` (un nom commençant par un point serait masqué par macOS)
- Build : CI GitHub Actions ; le dernier build est dans la release « latest »
- macOS (non notarisé) : `xattr -dr com.apple.quarantine DOT50.vst3`
